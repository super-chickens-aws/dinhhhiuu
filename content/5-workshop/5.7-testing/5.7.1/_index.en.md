## Test User Authentication

After deploying the application, we should verify that the authentication system works correctly.

The authentication flow is implemented using **Amazon Cognito** and protects all authenticated features of the Polly Voice application.

---

## Test Scenario

Verify the following user actions:

- Sign up with a new account.
- Confirm the account (if email verification is enabled).
- Sign in with valid credentials.
- Sign out.
- Attempt to access protected pages without authentication.

---

## Step 1. Sign Up

1. Open the Polly Voice application.
2. Navigate to the **Register** page.
3. Enter:

   - Email
   - Password
   - Confirm Password

4. Click **Create Account**.

The application should display a successful registration message.

> 📷 **Screenshot:** Register Page

---

## Step 2. Sign In

1. Navigate to the **Login** page.
2. Enter the registered email and password.
3. Click **Sign In**.

The application should redirect to the Dashboard.

> 📷 **Screenshot:** Successful Login

---

## Step 3. Verify JWT Authentication

After signing in:

1. Open the browser Developer Tools.
2. Navigate to the **Application** tab.
3. Check the browser storage.

Verify that Cognito authentication tokens are stored successfully.

Examples include:

- ID Token
- Access Token
- Refresh Token

> 📷 **Screenshot:** Cognito Tokens

---

## Step 4. Verify Protected Pages

While signed in:

- Refresh the browser.
- Confirm that the Dashboard remains accessible.

After signing out:

- Attempt to open the Dashboard URL directly.

The application should redirect back to the Login page.

> 📷 **Screenshot:** Redirect to Login

---

## Expected Result

The authentication system is considered successful if:

- Users can register successfully.
- Users can log in successfully.
- JWT tokens are generated by Amazon Cognito.
- Protected pages require authentication.
- Unauthorized users cannot access the Dashboard.
- Users can sign out successfully.

This confirms that Amazon Cognito has been integrated correctly with the Polly Voice application.
