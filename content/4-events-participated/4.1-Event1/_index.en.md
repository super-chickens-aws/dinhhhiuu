## Purpose of the Event

The FCAJ Community Day was organized to provide students and technology enthusiasts with practical insights into modern cloud computing and Artificial Intelligence on AWS. The event focused on sharing real-world experiences from industry experts, introducing the latest AWS AI services, and demonstrating how cloud technologies are applied in enterprise environments.

The event also created opportunities for participants to learn from successful cloud practitioners, understand current technology trends, and prepare for future careers in cloud computing and AI.

---

## Speakers

The event featured speakers from AWS and several AWS Partners, including:

- AWS Community Speakers
- Cloud Thinker
- Renova Cloud
- Student Video Group
- Noventic

Each speaker shared practical experiences from real customer projects and demonstrated how AWS services are used to solve business challenges.

---

## Key Topics

### Cloud Startup Journey

The opening session shared the experience of building cloud-based solutions for enterprise customers.

Some key takeaways included:

- Challenges when migrating traditional systems to AWS Cloud.
- Benefits of adopting Cloud-First architecture.
- Practical lessons learned from implementing cloud solutions for businesses.
- Importance of designing scalable and maintainable cloud systems.

This session helped participants understand that cloud adoption is not only about technology but also about improving business efficiency.

---

### Voice AI on AWS

One of the most interesting sessions introduced the architecture of modern Voice AI systems.

The speakers explained:

- Overall architecture of Voice AI applications.
- Speech-to-Text (STT) and Text-to-Speech (TTS) workflows.
- Challenges of processing Vietnamese language because it is considered a low-resource language.
- How Amazon Bedrock can be integrated with foundation models to build intelligent Voice Agents.

A live demonstration showed how a Voice Agent could communicate naturally with users through speech.

This session was particularly valuable because it demonstrated how multiple AWS AI services can be combined to create complete conversational AI systems.

---

### AI for DevOps

Another session introduced how Artificial Intelligence can improve software operations.

Topics included:

- Using AI agents to investigate production issues.
- Automatically collecting logs from multiple AWS services.
- Root cause analysis using AI.
- Reducing Mean Time To Recovery (MTTR).
- Improving operational efficiency through automation.

The speakers emphasized that AI should assist engineers rather than replace them, allowing developers to focus on solving complex problems instead of repetitive operational tasks.

---

### Amazon Q for Human Resources

The event also demonstrated how Amazon Q can improve internal business processes.

Example use cases included:

- Resume screening.
- Candidate evaluation.
- Knowledge management.
- Internal document search.
- Workflow automation for HR departments.

These demonstrations showed that Generative AI is not limited to software development but can also enhance productivity across different business departments.

---

### Security and Amazon Q Integration

The final technical session discussed security considerations when integrating Amazon Q with enterprise systems.

The speakers explained:

- MCP (Model Context Protocol) architecture.
- Secure integration with third-party applications.
- Data privacy protection.
- Identity and permission management.
- Best practices for enterprise AI deployment.

This session highlighted that security should always be considered from the beginning when developing AI applications.

The knowledge gained from this event can be applied to my Polly Voice project in several ways.

The event inspired me to think beyond simply calling Amazon Polly APIs.

I learned that a complete AI application should include authentication, storage, monitoring, and secure API communication.
