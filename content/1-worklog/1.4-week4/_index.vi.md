## Mục tiêu

- Tìm hiểu mô hình Serverless trên AWS.
- Hiểu cách hoạt động của AWS Lambda và Amazon API Gateway.
- Xây dựng các API đầu tiên cho dự án.
- Kết nối API Gateway với Lambda.

---

## Nội dung thực hiện

Trong tuần thứ tư, tôi bắt đầu xây dựng phần Backend của dự án theo kiến trúc Serverless.

Đầu tiên, tôi tìm hiểu cách hoạt động của AWS Lambda, cơ chế thực thi theo sự kiện (Event-driven) và những ưu điểm của mô hình Serverless so với việc triển khai ứng dụng trên máy chủ truyền thống.

Tiếp theo, tôi nghiên cứu Amazon API Gateway để xây dựng các HTTP API, cho phép ứng dụng Frontend giao tiếp với các hàm Lambda thông qua các endpoint.

Các công việc đã thực hiện gồm:

- Tạo các hàm Lambda.
- Cấu hình Runtime và IAM Role cho Lambda.
- Viết mã xử lý nghiệp vụ cho từng hàm.
- Tạo HTTP API bằng Amazon API Gateway.
- Cấu hình Route và Method cho từng API.
- Liên kết API Gateway với Lambda.
- Kiểm thử API bằng Test Event và HTTP Request.

---

## Kiến thức đạt được

Sau tuần thứ tư, tôi hiểu được:

- Mô hình Serverless trên AWS.
- Cơ chế hoạt động của AWS Lambda.
- Vai trò của Amazon API Gateway.
- Quy trình xử lý yêu cầu từ Frontend đến Backend.
- Cách triển khai và kiểm thử API trên AWS.

---

## Kết quả

Hoàn thành Backend Serverless đầu tiên cho dự án và xây dựng được các API phục vụ cho việc phát triển ứng dụng trong các tuần tiếp theo.
